# User Documentation

End-user guidance for the ERP project.

## Getting Started

### Login

1. Open the application (web: `http://localhost:3000`, desktop: Electron app)
2. Enter your username/email and password
3. Click "Connexion"

### First Login

If no users exist, the backend will automatically seed test data:
- **Tech Solutions SARL** - Username: `tech`, Password: generated and shown in logs
- **Green Import** - Username: `green`, Password: generated and shown in logs

### Navigation

- **Sidebar**: Access all modules (Dashboard, Products, Clients, Sales, etc.)
- **Top Bar**: Search, notifications, quick actions
- **Breadcrumbs**: Navigate back through module hierarchy

## Modules

### Dashboard
View KPIs, top products, alerts, and sales statistics.

### Products
Manage your product catalog with categories, pricing, stock levels, and barcodes.

### Clients
Manage client information, history, and balances.

### Sales
Create and manage sales, quotes, and delivery notes.

### Inventory
Track stock movements, alerts, and inventory counts.

### Suppliers
Manage supplier information and purchase orders.

### Purchases
Manage purchase orders, receptions, and supplier invoices.

### Delivery
Track deliveries, drivers, vehicles, and routes.

### HR
Manage employees, attendance, salaries, and bonuses.

### Accounting
Manage chart of accounts, journal entries, and treasury.

### Documents
Generate PDFs, quotes, and contracts from templates.

### AI
Access AI-powered forecasts, anomaly detection, and recommendations.

### Subscription
Manage your subscription plan and billing.

### Super Admin
Administrative interface for managing tenants, subscriptions, roles, and users.

## Public Features

### Marketplace
Browse products from multiple companies without an account.

### Order Tracking
Track your orders using the order reference number.

## Keyboard Shortcuts

| Shortcut | Action |
|----------|--------|
| `CMD+K` / `CTRL+K` | Command palette |
| `CMD+N` | New entry |
| `CMD+E` | Export current view |
| `CMD+F` | Focus global search |
| `CMD+B` | Toggle sidebar |
